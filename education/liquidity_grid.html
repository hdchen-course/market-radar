通用觀念在美股 / 黃金白銀的有限適用方式

流動性結構

什麼是流動性？

在交易市場中，流動性是指「以有限的價格衝擊快速成交的能力」，常以買賣價差、可見與隱藏的掛單深度、成交量、價格衝擊，以及大單成交後深度恢復的速度來衡量。

交易圈常把「停損單聚集區」口語地稱作「流動性池」（Liquidity Pool），意思是那裡一旦被觸發、會湧出較多市價單。但要注意：尚未觸發的停損單並不是可直接成交的掛單簿流動性 — 它要等價格觸及、轉成市價單或限價單後，才會真正參與成交。把「流動性」直接等同於「停損集中地」是一種口語簡化，不是嚴謹定義。

常見說法：技術分析圈流行一句話 —「價格會傾向移動到流動性所在的地方」。這是一個流行的觀察框架，而非已被普遍驗證的因果定律；可當成「為什麼價格常在明顯停損區附近假突破再反轉」的解讀角度，但不能用來精準預測主力路徑。

流動性池的位置

停損單（= 流動性）通常聚集在以下位置：

位置類型為什麼有流動性範例
前高/前低技術分析教科書教多數人把停損放在前高上方 / 前低下方BTC 前低 $94,200 → 多單的停損（sell stop）常掛在 $94,200 下方；前高上方則常見空單停損（buy stop）
等高/等低（Equal Highs/Lows）多次觸及同一價位 = 更多人在那裡設停損三次觸及 $100,000 不破 → 大量買入停損在 $100,050
整數關口心理價位，人類偏好在整數設停損和掛單$60,000、$65,000、$70,000
SuperTrend 線附近許多交易者以 ST 線作為停損參考位4H ST 在 $96,500 → 停損集中在 $96,200-$96,500
布林帶上下軌均值回歸交易者的停損區域BB 下軌 $62,000 → 停損在 $61,800
公允價值缺口（FVG）Smart Money Concepts 用三根 K 線定義的圖形（第二根留下未被第一、三根覆蓋的價格區間）；屬流行技術分析框架，不代表該區間「沒有成交量」，也沒有必然回補的機制$95K→$97K 快速移動後，三根 K 線間留下未重疊區間 = FVG（是否回補需自行回測，無固定機率）

如何在圖表上辨識流動性區域

視覺線索 1：多次觸及的水平線

  • 畫出被觸及 2 次以上但未突破的高/低點
  • 觸及次數越多 = 流動性越厚
  • 觸及次數多的價位，常被視為「停損較密集」的區域；但「第幾次一定會突破」沒有統計根據，不可當成必然

視覺線索 2：整數 + 密集成交

  • 看訂單簿深度（Order Book Depth）
  • 整數價位上方/下方通常有大量掛單
  • Heatmap（熱力圖）工具可直觀看到

視覺線索 3：Swing Point 密集區

  • 多個 Swing High 集中在相近價位
  • 代表多次嘗試突破 = 多次停損堆積
  • 這類區域常被形容為「磁鐵」，但這只是比喻；價格是否、何時會到達並無保證

視覺線索 4：長期盤整區的邊界

  • 盤整時間越長 = 兩側堆積的流動性越多
  • 突破時流動性被觸發 = 加速移動
  • 盤整越久，兩側累積的掛單與停損可能越多；但「幾天後突破必定劇烈」沒有固定門檻，僅為觀察經驗

訂單簿深度（Order Book Depth）

訂單簿只顯示「特定交易所、當下可見」的掛單分布，並不包含隱藏單（hidden／iceberg）與場外（off-exchange）流動性，也不等於「所有未成交單」。它能告訴你的是：

// 買方流動性（Bid Side）
$60,000: 150 BTC 掛單
$59,500: 80 BTC 掛單
$59,000: 320 BTC 掛單 ← 厚流動性牆

// 賣方流動性（Ask Side）
$61,000: 120 BTC 掛單
$61,500: 90 BTC 掛單
$62,000: 280 BTC 掛單 ← 厚流動性牆

// 解讀
- 大掛單可能是真實的供需，也可能稍後被撤走
- 合法撤單在市場上非常普遍；掛單在價格靠近時消失，本身不等於 spoofing
- spoofing 指「下單時即無成交意圖、純為誤導」，在法律上需能證明當事人當下的意圖，光看撤單無法斷定
注意：訂單簿可以被操縱，大額掛單不一定代表真實意圖。但反過來，撤單也可能只是正常的報價調整 — 不能一看到大單消失就認定是 spoofing。另外要留意：停損單同樣可以被取消或修改，並非「無法撤回」；把停損想成一定會成交的流動性是過度簡化。

為什麼價格會趨向流動性？

  1. 大額成交的需求：要分清「做市商（market maker）」和「大型方向性買家（大型資產管理人／趨勢交易者）」是不同角色 — 做市商靠雙邊報價賺價差、通常不長期持有大額單向部位；真正想買進 100,000 BTC 的是大型方向性買家。這類大單無法一次在市場完成，需要分批在成交量充足的地方吃單，因此偏好在流動性較厚的區域成交。
  2. 停損觸發的連鎖反應：當價格觸及停損密集區，停損被觸發 = 市價單湧入 = 更多停損被觸發 = 瀑布效應。這為主力提供了充足的對手盤。
  3. 成交量需求：機構交易者需要足夠的成交量來建倉/出貨。流動性池 = 高成交量區 = 機構的「提款機」。
  4. 路徑最小阻力（觀察性假說）：部分交易者認為價格傾向走向掛單／停損較多的方向。這是一種常見解讀而非定律，不能用來精準預測下一步方向。

流動性核心法則

  • 嚴謹定義：流動性 = 以有限價格衝擊快速成交的能力；口語常把「停損聚集區」稱為流動性池
  • 「價格傾向移向流動性」是流行的觀察框架，不是已驗證的因果定律
  • 前高前低、等高等低、整數關口 = 市場公認最明顯的停損／掛單聚集區
  • 觸及次數越多的水平線，常被視為停損越密集；但「被突破」沒有必然性
  • 盤整越久，兩側累積的掛單可能越多；突破的幅度與時點無固定規律
  • 理解這些聚集區 = 多一個解讀價格為何常在此假突破的角度，而非預測工具

主力獵殺（Liquidity Hunt）

什麼是流動性獵殺？

流動性獵殺（Liquidity Hunt / Stop Hunt）是技術分析圈的一種解讀框架：它假設某些價格波動是大型參與者為了觸發停損密集區、取得對手盤而造成的。要特別留意 — K 線與影線只能證明「這段期間價格走過哪裡」，無法證明背後存在某個主力「故意推價獵殺」的意圖。以下模式請當成觀察與風險管理的視角，不是對主力動機的事實陳述。

// 獵殺的基本模式
1. 識別：找到停損密集區（前高/前低/整數關口）
2. 推動：用相對少量的資金把價格推到停損區
3. 收割：停損被觸發 = 大量市價單湧入 = 主力的對手盤
4. 反轉：主力完成建倉/出貨後，價格迅速反向移動

// 散戶的視角
「明明走對了方向，就差一點被掃掉停損，然後就飛了」
→ 這就是典型的流動性獵殺

三種主要獵殺模式

掃流動性 Liquidity Sweep（流動性掃蕩）

定義：價格快速穿越前高/前低，觸發停損後立即反轉。通常在單根或極少根 K 線內完成。

特徵：

  • 突破前高/低後不持續，立即回撤
  • 留下長長的上/下影線（Wick / Shadow）
  • 收盤價回到突破前的區間內
  • 成交量在突破瞬間暴增然後驟降

範例：BTC 前低 $94,200，價格跌到 $93,900（穿越 $300），1 小時後回到 $95,500。$93,900-$94,200 這段就是「掃蕩」。

假突破 Fake Breakout（假突破）

定義：看似突破重要技術位但隨後失敗，價格反向移動。持續時間比 sweep 稍長（數小時到一天）。

特徵：

  • 突破時成交量不足（真突破應放量）
  • 突破後價格在突破位上方/下方猶豫不前
  • 後續 K 線實體逐漸縮小（動能衰竭）
  • 最終一根大陰/陽線吞沒突破 = 確認假突破

範例：BTC 盤整上軌 $68,000，突破到 $68,500 後橫盤 6 小時，量能萎縮，隨後暴跌到 $66,000。

SMC 獵殺 Smart Money Concept 完整獵殺

定義：完整的三步驟主力操作模式：掃流動性 → 位移（Displacement）→ 公允價值缺口（FVG）。

三步驟：

  1. 流動性抓取（Liquidity Grab）：價格穿越關鍵位觸發停損
  2. 位移（Displacement）：緊接著出現連續大實體 K 線反向移動（主力真正的方向）
  3. 公允價值缺口（Fair Value Gap / FVG）：位移過程中留下的價格真空區域 = 未來的回踩目標

範例：BTC 掃 $94,200 低點 → 出現連續 3 根大陽線從 $94,000 漲到 $97,000（位移）→ $95,000-$95,800 之間有 FVG → 後續回踩到 $95,400（FVG 中間）後繼續上漲。

如何辨識獵殺 vs 真突破

判斷要素是獵殺（假突破）是真突破
突破後動能突破後價格猶豫、停滯、回撤突破後價格加速遠離突破點
成交量突破瞬間有量但後續量能萎縮突破時放量且後續維持高量
K 線形態長影線、十字星、紡錘線大實體 K 線、無/短影線
收盤位置收盤回到突破前區間內收盤遠離突破點（> 0.5-1%）
時段低流動性時段（亞洲清晨、假日）高流動性時段（歐美交疊）
多時框配合僅 1H 突破、4H/日線未確認多時框同時突破
後續走勢形成反向大 K 線（吞沒）形成高低點不斷抬升/降低

用影線（Wick）辨識掃蕩

// 影線判讀規則

長下影線 + 小實體 = 下方流動性被掃蕩後買壓進場
長上影線 + 小實體 = 上方流動性被掃蕩後賣壓進場

// 有效掃蕩影線的標準
1. 影線長度 > 實體的 2 倍以上
2. 影線穿越了明確的流動性位（前高/前低/整數）
3. 收盤價回到流動性位的正確一側
4. 該 K 線成交量明顯高於前 5 根平均

// 操作含義
看到有效掃蕩影線 → 等下一根 K 線確認方向 → 順反轉方向入場
止損：影線最末端 + buffer

SMC 簡化模型：獵殺 → 位移 → FVG

Smart Money Concepts（聰明錢概念，SMC）是一套流行的技術分析框架，目前並無普遍接受的因果驗證。其核心是一個三步驟模型：

1
流動性抓取（Liquidity Grab）
價格快速穿越已知的流動性池（前高/前低）。特徵：長影線、快速回撤。
這一步的目的：觸發散戶停損 = 主力獲得對手盤
2
位移（Displacement）
掃蕩完成後，出現連續 2-3 根大實體 K 線向反方向移動。
這一步確認：主力的真正方向 = 位移的方向
3
公允價值缺口（Fair Value Gap / FVG）
位移過程中，第二根 K 線的高低點與第一、三根 K 線之間出現「缺口」（沒有重疊的價格區域）。
FVG 常成為價格的回踩目標，但填補的機率沒有固定數值、也可能不回補，須自行回測驗證
實戰應用（SMC 框架內的做法，非保證）：有些交易者會在 FVG 中間位置掛限價單（需用交易所的 post-only 才能確保是 Maker），止損放在掃蕩影線的最末端。支持者認為這樣風報比較好，但「FVG 高機率觸及、掃蕩極值低機率再測」這些機率並無固定數值，須自行回測，不能視為保證。

獵殺發生的時機

  • 亞洲時段尾聲 → 歐洲開盤：亞洲盤整的高/低點是獵殺目標
  • 重大數據公布前 15 分鐘：低流動性 + 恐慌 = 容易掃蕩
  • 週一開盤：掃蕩週五的高/低點
  • 假日薄盤：少量資金就能推動價格到流動性區
  • 長期盤整後：兩側流動性都很厚，先掃一側再往另一側走

散戶如何自保

  • 不要把停損放在「明顯」的位置（正好在前高/前低）
  • 停損 = 前高/前低 + 1-2 ATR buffer → 降低被正常波動掃到的機率（但停損放遠會增加每單位風險，須同步縮小部位，帳戶風險才不變）
  • 看到長影線掃蕩後的反轉 = 可考慮跟隨反轉方向，但仍須確認與風控
  • 「被掃蕩」不一定代表判斷錯誤，也不能一概歸因「停損設太緊」 — 可能只是該筆交易的正常結果
  • 學會在 FVG 回踩時入場，而不是在突破瞬間追單

低波動環境辨識

為什麼需要辨識低波動？

SuperTrend 等趨勢指標在低波動、無方向的環境中容易產生假訊號。不過要特別澄清：網格策略真正需要的不是「單純的低波動」，而是價格在區間內持續來回震盪、且已實現波幅足以覆蓋所有成本。若波動低到價格幾乎不動、格線之間沒有可配對的成交，網格一樣賺不到錢。辨識環境的目的，是判斷此刻比較適合趨勢系統還是區間／網格系統。

低波動的五大辨識指標

1. ATR 壓縮

  • ATR(14) 低於過去 60 日平均的 50% 以下
  • 4H ATR 和日線 ATR 同時壓縮 = 雙重確認
  • ATR 壓縮持續 > 3 天 = 可以開始準備網格
  • 極端壓縮：ATR 創 30 日新低

2. 布林帶擠壓（BB Squeeze）

  • 上下軌距離收窄到歷史低位
  • BB 帶寬（BandWidth）< 過去 120 日最低值
  • K 線在 BB 中軌附近密集排列
  • 擠壓越極端 = 未來突破越猛烈

3. 成交量萎縮

  • 日成交量低於 20 日平均的 50%
  • 連續 3 天以上低量
  • BTC 24h 成交量創近期新低
  • 低量 = 無方向性 = 趨勢策略無效

4. 連續小實體 K 線

  • 連續 5 根以上 K 線實體 < ATR 的 30%
  • 紡錘線、十字星頻繁出現
  • 無明確的高低點推進
  • 視覺上 K 線像「螞蟻在爬」

5. 資金費率趨近零

  • 永續合約 Funding Rate 在 -0.005% ~ +0.005%
  • 代表多空力量完全均衡
  • 無方向偏差 = 無趨勢 = 適合網格
  • Funding 持續中性 > 3 天 = 強信號

SuperTrend 為什麼在低波動中失靈？

// 正常環境
ATR(300) = $2,000 → ST 線離價格 $6,000（3 倍 ATR）
→ 微小波動觸發不了翻轉 → ST 信號可靠

// 低波動環境
ATR(300) 壓縮到 $800 → ST 線離價格僅 $2,400
→ 日常波動就可能觸及 ST 線 → 頻繁假翻轉

// 結果
1. ST 翻多 → 你做多 → 沒趨勢 → 價格回落到 ST 線 → 翻空
2. ST 翻空 → 你做空 → 沒趨勢 → 價格反彈到 ST 線 → 翻多
3. 反覆被來回打臉 → 連續虧損 → 心態崩潰

// 正確做法
辨識低波動 → 關閉 ST 交易系統 → 啟動網格策略

關鍵判斷：低波動的「原因」會影響是否適合開網格。「重大事件前」的低波動較不適合開網格（事件可能打破區間）。「崩盤後盤整」和區間（Range-bound）市場相對理想，但也要記得 — 突破不是只有重大事件才會造成，流動性變化、連鎖清算、情緒轉向等都可能讓區間失守，沒有任何環境能保證網格安全。

低波動 → 高波動的轉折信號

當以下信號出現時，準備關閉網格、切回趨勢模式：

  • BB 帶寬開始擴張：上下軌開始分離 = 壓縮結束
  • 突然出現大實體 K 線：實體 > 前 10 根 K 線的平均 2 倍
  • 成交量暴增：24h 量 > 20MA 的 150%
  • Funding Rate 偏離零值：|FR| > 0.03% = 方向性出現
  • 價格突破 5 日 High/Low：脫離近期盤整區間

網格交易策略 SOP crypto 選修

以下網格 SOP 為加密專用的選修進階內容，不適用於美股與貴金屬的核心波段策略。網格在單邊趨勢行情容易受重傷，非本站主線。

什麼是網格交易？

網格交易（Grid Trading）是在一個價格區間內，等距設置一系列買入和賣出限價單，當價格在區間內來回波動時自動低買高賣。要注意：單獨一次成交（fill）本身不會產生已實現利潤 — 利潤來自「買入的 fill」與後續「對應的賣出 fill」配對完成的一整個循環；只買到卻還沒賣出，那段只是浮動部位。

// 網格基本概念
區間上限 (Upper): $64,000
區間下限 (Lower): $60,000
格子數量 (Grids): 20 格
每格間距: ($64,000 - $60,000) / 20 = $200

// 運作邏輯
每個格子 = 一個掛單位
價格下跌到某格 → 觸發買入限價單
價格上漲到上一格 → 觸發賣出限價單
每次「買了又賣」= 賺一個格子的價差（$200）

// 網格的特性（不是穩賺）
- 網格並非「不預測方向」，而是下注價格會在這段期間反覆穿越格線、且已實現波幅足以覆蓋全部成本；一旦走單邊，一側會持續被套
- 掛單須未立即成交、確實增加了掛單簿流動性才算 Maker；要保證掛單是 Maker 需用交易所支援的 post-only，費率也依交易所與等級而定，不一定是零或負
- 可 24/7 自動運作，不需緊盯盤
- 只有在價格持續於區間內震盪時才會穩定產生現金流

何時部署網格 — 啟動條件

1
確認低波動環境
低波動評分 >= 7 分。ATR 壓縮 + BB 擠壓 + 成交量萎縮至少三項同時出現。
2
確認無即將到來的重大事件
查看經濟日曆：未來 48 小時內無 Tier 1 事件（CPI、FOMC、非農、央行利率決議）。
若有事件 → 不開網格，等事件結束後 24 小時再評估。
3
確認日線 ST 方向穩定
日線 ST 在同一方向持續 > 7 天（非剛翻轉）。
若日線 ST 剛翻轉 < 3 天 → 可能還在趨勢中，不適合網格。
4
確認價格在明確區間內
過去 5 天的價格都在一個 < 5% 的範圍內波動。
能明確畫出上軌和下軌。

網格參數設定 SOP

參數計算方式備註
區間上限近 5 日最高價 + 0.5 ATR(4H)留 buffer 避免太容易被突破
區間下限近 5 日最低價 - 0.5 ATR(4H)同上
格子間距0.3 ~ 0.5 倍 4H ATR間距太小 = 手續費吃掉利潤；太大 = 觸發次數少
格子數量（上限 - 下限）/ 間距此處 15-30 格僅為示例區間，非通用鐵律；實際取決於資產、波幅與成本
每格倉位總資金 / 格子數量確保所有買單都能被填充
總資金示例：不超過帳戶的一小部分（本文以 20% 為例）20% 是本教材採用的示例上限，非市場通用鐵律；實際比例應依個人風險承受度與整體部位決定
// 計算範例
帳戶資金: $50,000
網格分配: $50,000 * 20% = $10,000

4H ATR: $800
5 日最高: $63,500 / 5 日最低: $61,000

區間上限: $63,500 + $400 = $63,900
區間下限: $61,000 - $400 = $60,600
區間寬度: $63,900 - $60,600 = $3,300

格子間距: 0.4 * $800 = $320
格子數量: $3,300 / $320 ≈ 10 格
每格資金: $10,000 / 10 = $1,000
每格 BTC: $1,000 / ~$62,000 ≈ 0.016 BTC

// 收益只是「某段區間」的示意，不是可外推的報酬
每格利潤: $320 * 0.016 BTC ≈ $5.12（單格、單次填充的示意值）

這個數字只成立於「價格剛好持續在區間內來回震盪」的那段時間。
盤整能維持多久無法預測，把單日示意值乘以 30 天推成「月化報酬」是
錯誤的線性外推 — 一旦走出單邊趨勢行情，網格會在錯的方向持續持倉、
產生虧損，實際結果可能是負的。

結論：以上僅為過去某段區間的示意，不代表未來，趨勢行情下會虧損。

三種網格類型

中性網格（Neutral Grid）

適用：無方向偏好，純粹區間震盪

設定：當前價格在區間正中間。上下均勻分布格子。

特點：

  • 上半部 = 持有空單（每格賣出）
  • 下半部 = 持有多單（每格買入）
  • 不預判方向，雙向賺錢
  • 最大風險：價格離開區間

多頭偏向網格（Long-biased Grid）

適用：日線 ST 多，但短期盤整無方向

設定：只設買入格子（下方）。當價格回落時買入，上漲時分批賣出。

特點：

  • 只在下跌時建倉
  • 格子都設在當前價格下方
  • 如果價格一路上漲 = 沒有成交（錯過）
  • 如果價格下跌 = 分批接貨（低於市價）

空頭偏向網格（Short-biased Grid）

適用：日線 ST 空，但短期盤整反彈中

設定：只設賣出格子（上方）。當價格反彈時分批做空，下跌時分批平倉。

特點：

  • 只在上漲時建空倉
  • 格子都設在當前價格上方
  • 順日線大方向做空 = 安全邊際高
  • 如果趨勢反轉上漲 = 需要嚴格止損

Maker 費率優勢

網格策略的隱藏優勢：所有掛單都是限價單（Maker Order）。

以下費率僅為撰寫時的示意，交易所費率高度時效化，且依 VIP 等級／幣對／合約類型而異，請以各交易所官方費率頁的最新數字為準（下表為示例，未附確切 as-of 日期，不應直接拿來計算真實損益）。

交易所（示例）Maker 費率Taker 費率說明
Binance（VIP 0）約 0.02%約 0.04%Maker 比 Taker 省約 0.02%
Binance（較高等級）可能趨近 0%約 0.035%即使手續費趨近零，仍非「純利潤」（見下）

網格 + Maker 的成本優勢：當格子間距是 $320（≈ 0.5%）、Maker 費率趨近 0% 時，手續費對每格價差的侵蝕確實很小。但「Maker 0%」不代表零成本、更不是純利潤：你仍要承受買賣價差（spread）、逆向選擇（adverse selection，你的掛單往往在對你不利時先成交）、永續合約的資金費率（funding）、稅負，以及現貨與合約之間的基差成本。這些都不會出現在手續費欄位裡。而且只要價格走出單邊趨勢，一側持倉被套的虧損會遠大於所有格子價差。低成本不等於低風險，更不等於穩賺。

網格的陷阱與限制

  • 單向行情 = 災難：如果價格直接穿越區間一路走掉，所有一側的單都被填充，另一側全空 = 持倉被套
  • 資金效率低：20% 帳戶資金分散在所有格子中，大部分時間只有少數格子在工作
  • 不適合高波動：ATR 突然擴大 = 區間被打破 = 網格失效
  • 心理陷阱：看到一側持倉越來越多（一邊倒）會焦慮，可能過早關閉
  • 事件風險：黑天鵝事件可能讓價格瞬間穿越整個網格 = 單向持倉爆滿

網格風險管理 crypto 選修

本頁風控規則是為加密網格設計的選修內容，不套用於美股與貴金屬波段。美股與貴金屬的資本保全，請以部位控管與 ATR 緩衝止損為主。

每日審查清單

網格運行期間，每天必須檢查以下項目：

1
價格是否仍在區間內？
確認當前價格在網格上限和下限之間。若觸及邊界但未突破 = 暫時安全但需提高警覺。
2
日線 ST 方向是否改變？
日線 ST 翻轉 = 可能從盤整轉為趨勢 = 網格環境結束的信號。若翻轉方向 = 網格被套的方向 → 立即關閉。
3
ATR 是否開始擴張？
4H ATR 相比開網格時增加 > 50% = 波動率回升 = 區間可能被突破。準備關閉網格。
4
未來 24-48h 有無 Tier 1 事件？
CPI、FOMC、非農、央行利率決議。若有 → 事件前 4-12 小時關閉網格或暫停。
5
網格持倉是否過度偏向一側？
若所有買單都已成交但無賣單成交 = 持倉全在一側 = 接近被套邊緣。考慮主動減倉。
6
資金費率是否大幅偏離零？
|Funding Rate| > 0.05% = 市場開始有方向偏好 = 盤整可能結束。

殺手開關（Kill Switch）— 必須關閉網格的條件

立即關閉網格的觸發條件（任一即觸發）

  1. 日線 ST 翻轉：趨勢方向改變 = 盤整結束 → 立即平倉所有網格持倉
  2. 價格突破區間 > 1 ATR(4H)：不是只碰到邊界，而是遠離邊界超過一個 ATR = 確認離開區間
  3. Tier 1 事件即將在 24h 內發生：CPI/FOMC/非農 = 會造成劇烈波動打破區間
  4. 單方向連續行情 > 3%：連續數小時不回調的單向移動 = 趨勢啟動
  5. 成交量突然暴增 > 20MA 的 200%：巨量 = 大資金進場 = 方向性移動即將發生
  6. 連續 24h 無任何格子觸發：價格已離開活躍區域 = 網格形同虛設

網格被套：一邊倒持倉的處理

當價格移動到網格一側邊界，所有同方向的單都被填充：

情境 A：全部買單被填充

狀態：價格從上方跌到下方，所有買入格子都成交了。你持有大量多頭持倉，浮虧中。

決策流程：

  1. 價格仍在區間下限附近（未突破 > 1 ATR）→ 觀察，可能只是掃蕩下方流動性後反彈
  2. 價格突破下限 > 1 ATR 且日線 ST 翻空 → 認賠平倉，不要期待反彈
  3. 價格突破下限但日線 ST 仍多 → 平一半持倉，剩餘設止損在區間下限 - 2 ATR
情境 B：全部賣單被填充

狀態：價格從下方漲到上方，所有賣出格子都成交了。你持有大量空頭持倉，浮虧中。

決策流程：

  1. 價格仍在區間上限附近（未突破 > 1 ATR）→ 觀察，可能只是假突破
  2. 價格突破上限 > 1 ATR 且日線 ST 翻多 → 認賠平倉，趨勢已啟動
  3. 價格突破上限但日線 ST 仍空 → 平一半，剩餘設止損在區間上限 + 2 ATR

資金恢復策略

網格被套認賠後，如何恢復資金：

1
停止操作 24-48 小時
認賠後的情緒狀態不適合交易。給自己冷靜期。不要報復性加倉或立即開新網格。
2
重新評估環境
網格被突破 = 市場從盤整轉為趨勢。此時應切回 ST 趨勢策略，而非開新的網格。
3
降低下一筆的倉位
虧損後下一筆交易倉位減半。用小倉位慢慢恢復信心和資金。連續盈利 3 筆後再恢復正常倉位。
4
記錄並改進
為什麼被套？是忽略了殺手開關的信號？還是參數設太窄？記錄下來，下次避免。

網格資金管理原則（以下數字為本教材示例，非通用鐵律）

  • 控制投入比例（本文以不超過 20% 為例）：若區間被打破，可能虧損整個網格配置的相當比例；把投入控制在帳戶一小部分，是為了讓單一事件的衝擊可承受。20% 為示例，非通用鐵律。
  • 避免用槓桿做網格：網格本身已佔用大量資金，加槓桿會放大被套與爆倉風險。
  • 避免在同一資產疊多組重疊網格：容易在同方向過度集中。
  • 控制所有網格的加總曝險（本文示例合計上限 40%）：例如同時在 BTC、ETH 配置時合計不超過某個比例；數字為示例，依個人風險承受度調整。
  • 設一條帳戶級停損（本文以 5% 為例）：不論其他條件如何，帳戶級止損是最後防線；5% 為示例門檻，非固定標準。

網格風控總結

  • 網格是「有限環境」工具 — 只在確認的低波動區間使用
  • 每日審查是非談判性義務 — 跳過一天可能錯過殺手開關信號
  • 20% 資金上限是帳戶生存的保險 — 永遠不違反
  • 殺手開關 = 不猶豫的機械式行動 — 觸發就關，不期待
  • 被套認賠 = 正常成本 — 重要的是控制每次虧損 < 帳戶 5%
  • 網格只是工具箱中的一個工具 — 不是所有環境都適用
