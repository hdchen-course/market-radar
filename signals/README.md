# 白銀(XAG)每日傾向工具 — 使用手冊

> ⚠️ **實驗性工具,非投資建議。** 樣本外驗證(2006-2016訓練/2017-2026驗證)尚未完成,
> 15-42 條件可能殘留偽陽性;偏空側結構性失效(做空幫助有限)。核心價值是「擋掉會賠錢的
> 直覺」而非給神奇買賣點。可靠度須靠上線後逐日記錄實績驗證,勿在驗證前當進場依據。

一個 agent team(data / driver / signal / macro / reviewer + lead)研究白銀過去一年驅動因子、
用 20 年日線 + 40 年 CFTC + 262 日 LBMA 回測後,蒸餾出的**每日可用工具**。

## 怎麼跑

```bash
cd signals && ./setup.sh
```

自給自足:首次執行自動建 `.venv`、裝 `requirements.txt`、跑工具(約 30-40 秒);
之後執行偵測到依賴已就緒就跳過安裝、直接跑(約 5 秒)。
依賴改過(requirements.txt 更新)會自動重裝。強制重建用 `./setup.sh --reinstall`。

抓當日免費數據(Yahoo SI=F/GC=F/^VIX/CL=F + CFTC 免費 API),比對 `rulebook.json`,
輸出綜合傾向,並寫一份 `last_run.json` 供程式化使用。

> 不再依賴 `/tmp`。`.venv/` 已列入 .gitignore,不會進版控。

## 輸出怎麼讀(重要,順序不能反)

1. **綜合傾向**(偏多/觀望/偏空 + 分數):觸發的訊號與背景燈的加權和。
   - `>=+5` 偏多高信心 / `+2~+4` 偏多低信心 / `-1~+1` 觀望 / `<=-2` 偏空
2. **觸發的進場訊號**:只有「可獨立進場」判定才單獨開倉。每條附:
   - **命中率 / 樣本N** — 準確度,但要搭配下一項看
   - **賭錯中位 / 最壞** — 「賭錯痛多少」的答案。這比命中率更該看。
   - **⚠ caveat** — 這條的硬傷(資料窺探、樣本、失效條件)
3. **VIX 環境**:VIX<15 時均值回歸訊號鈍化,權重要打折。
4. **地緣狀態燈**:只描述環境,不產生部位。

## 三件你必須知道的限制(誠實,不藏)

### 1. 嚴格意義上「乾淨到能閉眼進場」的訊號 = 0 條
測了 60+ 條規則,套完所有防過度擬合的檢定後:
- 全樣本最高分 **S3H(金銀比+2 且 金銀比>81.6→做多,US 77.8)**,但它的分層界是從歷史挑的(資料窺探),實盤要打折,三年窗口就掉到不可用。
- 較誠實的是母版 **S3(金銀比+2→做多,US 68.4,僅輔助)**,無資料窺探但只算輔助。

### 2. 工具幾乎給不出可靠的「偏空」訊號(結構性限制)
signal 和 driver 兩條線**獨立收斂**到:白銀所有穩健訊號都在**偏多側**,偏空側結構性失效——
因為銀的基準報酬分年代劇變(空頭市/多頭市切換),做空訊號在多頭年代必然失靈。
**想做空時,本工具能幫的有限,得靠籌碼/實體機制證據(COT、實體短缺),不能靠回測。**

### 3. 這些「直覺規則」已被數據證偽,工具不用(見 rulebook.refuted_do_not_use)
- ❌ 金銀比+2→銀「弱」(做空) — **方向就是反的**(這是最初的範例規則)
- ❌ 弱美元→買銀 — 20 年無前導性
- ❌ 油飆→殺銀 — 分年代符號翻轉;殺銀的是殖利率腿不是油
- ❌ COT 淨多極端→空銀(S1/S2) — 門檻脆弱、軋空全程從未觸發
- ❌ 日幣 carry / 新興市場 / 殖利率曲線 / VIX 當進場訊號 — 42 條宏觀規則 0 條顯著
- ❌ **投機空頭(COT short)分位/趨勢當訊號** — 45組+獨立240組grid回測 0 條通過(見下)

### 4. 投機空頭(COT short)只當「顯示層」,不當訊號
工具會顯示投機空單口數與分位(26週/52週/5年 + 全距),當作**查證背景數據**,但**回測後零規則可交易**:
- 「空頭低基期加碼→看空銀」(即 2026-08 當前狀況)**證偽**:做空命中 43.3% < 基準 47.8%、期望值為負。
- 「空頭分位極高→看多銀」是唯一撐過多輪攻擊的,但仍拒放行 —— 真死因是**報酬集中在 2010-11 白銀泡沫軋空**(剔除後 95%CI 含 0)+ 逐年 walk-forward 僅 5/8 年打贏(p=0.73)。它描述的是「一次歷史性軋空長相」,非可重複 edge。
- **COT 落後約 10 天**:實測 lag 敏感性顯示優勢在公布後 ~8 天內衰減完(lag6 有 edge → lag12 歸零 → lag16 轉負)。故**不得**用 COT 宣稱抓即時軋空頂底,只能看週級結構。
- 顯示空單分位時**必須同時給兩尺度 + 全距**:26週92% 與 5年9% 並存是極罕見狀態(歷史僅 0.1% 週),真因是 26週全距僅 6,551 口(帶寬差 8.8 倍),只寫「92%」會被誤讀成空單擁擠。原始口數跨 5 年受 OI 時代漂移影響**不可比**。
