# 事件分類器（買預期／賣事實）— 階段1 MVP

> ⚠️ **實驗性工具、非投資建議。** 這是「買預期賣事實 skill」的階段1，只做**數學上站得住的那一件事**：分標的、分事件類型的 **pre-event drift（財報前異常報酬）描述統計**。所有經對抗式審查判定「上線前不可驗證」的功能（賣事實做空訊號、surprise z-score 回測、無催化腿歷史回測、分鐘級新聞因果、猜特定真人意圖）**一律未實作或僅降級為描述層**，絕不進「可交易分數」。

## 這工具能給什麼
- **財報前 drift 傾向**：某晶片股（NVDA/MU/TSM/AMD）在財報前 5/10/20 日，相對半導體指數(^SOX)的累積異常報酬（CAR），歷史上系統性偏多/偏空/無方向，並誠實標出樣本多小、是否通過顯著性與逐年 walk-forward。
- **買預期/賣事實的描述性觀察**：財報前 CAR（買預期）vs 財報後 CAR（賣事實/利多出盡）並陳。
- **誠實的 verdict**：每個組合標「可參考傾向」（通過全閘門）或「僅描述」（未通過，不可當交易依據）。

## 這工具絕不能給什麼
- ❌ 「買漲/買跌」的可交易訊號 — 目前 0 個組合通過閘門。
- ❌ 有回測背書的 surprise z-score — 免費資料無歷史 point-in-time 共識。
- ❌ 賣事實「做空進場」訊號 — 偏空側結構性失效 + 樣本數數學上不可能過閘。
- ❌ 抓即時軋空頂底 — COT 落後約 10 天。
- ❌ 模擬川普/科技大佬「下一步想幹嘛」 — 通靈、零驗證，已砍。

## 放行閘門（全部通過才標「可參考傾向」）
1. **N_events ≥ 8**（樣本紅線，沿用白銀工具 hard_caps）
2. **binom p < 0.05**（方向一致性顯著）
3. **walk-forward 逐年方向一致 > 50% 年數**
4. 方向一致率須明顯偏離 50%
5. **禁止跨標的/跨事件類型池化**撐樣本（每檔分開報）
6. **5/10/20 三窗強制全報**，禁止事後挑最好看那檔

## 檔案
| 檔案 | 職責 |
|---|---|
| `data_layer.py` | yfinance 下載日線 → `data/prices.pkl`（不依賴 /tmp、參數化 as-of，防前視） |
| `events.py` | 財報日 + Reported EPS（**當時首刷值，無修訂 look-ahead**）→ `data/earnings.pkl` |
| `abnormal_return.py` | 市場模型 β 回歸 + CAR[-N,-1]，估計窗嚴格早於 drift 窗、留 gap |
| `backtest_drift.py` | 跑 5/10/20 三窗回測 + 全閘門 + 誠實 verdict |

## 怎麼跑
```bash
cd signals
.venv/bin/python event_classifier/data_layer.py --force   # 首次或更新價格
.venv/bin/python event_classifier/events.py --force       # 首次或更新財報日
.venv/bin/python event_classifier/backtest_drift.py       # 跑回測
```

## 2026-08-13 首次回測結果（誠實記錄）
- **12 組合（4 檔 × 3 窗）全部「僅描述」，0 個通過閘門。** 樣本約 21 事件/檔（6 年價格覆蓋），統計上撐不起可交易顯著性——**這是正確結果，不是失敗**（如白銀工具「乾淨到能閉眼進場的訊號=0 條」）。
- **浮現的描述性觀察（弱、僅參考）**：MU/TSM/NVDA 財報前 CAR 傾向偏多（N=20 時 NVDA 偏多 71%、CAR +2.1%），但**事後 CAR 多為負**（MU -1.2%、TSM -1.4%）——方向上**弱弱支持「買預期、賣事實」**（財報前漂多、財報後回吐），但**未達統計顯著，不可據此交易**。
